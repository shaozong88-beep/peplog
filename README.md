# PepLog official website & app preview

The official PepLog product website, available on phones and computers.

- Website: https://shaozong88-beep.github.io/peplog/
- Browser app preview: https://shaozong88-beep.github.io/peplog/app.html
- User Agreement: https://shaozong88-beep.github.io/peplog/terms.html
- Privacy Policy: https://shaozong88-beep.github.io/peplog/privacy.html

The website includes English and Chinese, current app screenshots with illustrative records, product features, membership information and FAQs. The iOS app is in development; there is no App Store download or payment on this website. Legal operator and contact details are still pending in the clearly labelled preview documents.

The retained React Native + Expo browser app:

- Includes Today, product Library, Protocol, Calculator and Me.
- Records stay in this browser's local storage. Clearing browser data removes them.
- Subscription prices are an explicitly labelled preview; no purchases are made.
- iPhone notifications and Apple in-app purchases require the installed iPhone app.
- A tracking and reference tool, not medical advice.

This repository contains the compiled website and app in `peplog-web.zip` and a GitHub Pages deployment workflow. It does not contain personal records, service credentials or private project documents.
