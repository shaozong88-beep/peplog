# PepLog browser preview

Public preview of the React Native + Expo app. Open the GitHub Pages website on a phone or computer.

- Includes Today, product Library, Protocol, Calculator and Me.
- Records stay in this browser's local storage. Clearing browser data removes them.
- Subscription prices are an explicitly labelled preview; no purchases are made.
- iPhone notifications and Apple in-app purchases require the installed iPhone app.
- A tracking and reference tool, not medical advice.

This repository contains compiled web assets in `peplog-web.zip` and a GitHub Pages deployment workflow. It does not contain personal records, service credentials or the private project documents.
